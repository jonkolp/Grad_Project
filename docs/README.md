## 📑 Literature Review & Reference Papers (`docs/papers/`)

The [`papers/`](papers/) subdirectory contains the benchmark literature and foundational research referenced in this study:

1. **Khobragade et al. (2016)**: *Automatic Detection of Major Lung Diseases Using Chest Radiographs and Classification by Feed-Forward Artificial Neural Network.*
2. **Detection & Classification of Lung Diseases for Pneumonia and COVID-19 (2023)**: Machine and deep learning comparison study.
3. **Alshmrani et al. (2022/2023)**: *A Deep Learning Architecture for Multi-Class Lung Diseases Classification Using Chest X-ray (CXR) Images* (Alexandria Engineering Journal).
4. **Shamrat et al. (2022) - LungNet22**: *A Fine-Tuned Model for Multiclass Classification and Prediction of Lung Disease Using X-ray Images* (Journal of Personalized Medicine).
5. **Kumar et al. (2023)**: *Automatic Lung Disease Classification from the Chest X-ray Images Using Hybrid Deep Learning Algorithm* (Multimedia Tools and Applications).
6. **Deep Chest Multi-Classification DL Model**: Architecture study for multi-disease screening.
7. **Lung Cancer Risk Prediction with Machine Learning Models**: Comparative analysis of predictive models.
8. **An Important Review**: Systematic literature review of AI and deep learning in respiratory diagnosis.
